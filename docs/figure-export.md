# Save figures

Choose **File → Settings → Figure format**:

- **PNG**: an image.
- **SVG**: editable regions, probes, electrodes, and annotations. Scan intensities stay as an embedded image.

Click the save icon above a scan or 3D view. The file is saved in the project's `figs` folder. The format choice is remembered.

In a 3D SVG, each brain region is a separate group. The file shows the current camera view; it is a 2D projection.

Electrophysiology uses **PDF**. Click its save icon and choose a folder. Regions are separate vector paths; region names, lines, and electrodes remain separate editable objects. The scan stays as an image.

Open SVG or PDF in Illustrator or Inkscape to edit the vector objects. Ungroup objects when needed.
